In Week 1, I learned the basics of how operating systems and the web work. First, I studied how to run Linux on a Windows machine using WSL, and I learned how data moves across networks using Public and Private IP addresses. I also learned the client-server model. I learned how to read HTTP messages line-by-line, including how request lines, headers, and data bodies work together. Finally, I studied different HTTP methods like GET and POST, server status codes like 200 OK, and how network tools like DNS, load balancers, web servers secure and manage.
