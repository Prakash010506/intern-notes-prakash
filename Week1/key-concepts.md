Client → Sends request

Server → Processes request

HTTP → Communication protocol

HTTPS → Secure HTTP

API → Communication between applications

REST API → API using HTTP methods

GET → Retrieve data

POST → Create data

PUT → Update data

DELETE → Remove data

Authentication → Who are you?

Authorization → What are you allowed to do?

DNS → Converts domain name to IP address

IP Address → Identifies a device/network

Port → Identifies a service

Web Server → Serves web content
Application Server → Runs application logic
