## 1. WSL

WSL stands for Windows Subsystem for Linux. It allows us to run a Linux environment directly on Windows.

Example: We can install Ubuntu on Windows using WSL.


## 2. Linux

Linux is an open-source, Unix-like operating system used on computers, servers, and other devices.

Examples: Ubuntu, Debian, Fedora.


## 3. Unix

Unix is a family of operating systems developed before Linux and is widely used in servers and enterprise systems.

Examples: AIX, Solaris, HP-UX.


## 4. Public IP

A public IP is an IP address used to identify a device or network for communication over the public Internet.

Example: A home router can have a public IP provided by the Internet Service Provider.


## 5. Private IP

A private IP is an IP address used to identify a device within a private network such as a home, office, or Wi-Fi network.

Example: 192.168.1.10


## 6. Client

A client is a device or application that sends a request to a server


## 7. Server

A server is a computer or application that receives requests from clients and sends responses.

## 8. Web Server

A web server receives HTTP requests from clients and sends web content or responses.

## 9. Application Server

An application server runs application code and handles application logic.


## 10. Web Server vs Application Server

Web Server:
Handles web/HTTP requests and can serve web content.

Application Server:
Runs application code and handles application logic.


## 11. Open Source

Open-source software is software whose source code is available under a license that allows people to use, view, modify, and share it according to the license terms.

Example: Linux is open-source software.

---

## 12. Is Open Source Always Free?

No. Open-source software may be available without a license fee, but users may still pay for hosting, support, maintenance, or other services.

---

## 13. Does "Free" Always Mean Money?

No. In software, "free" can mean freedom to use, modify, and share the software. It does not always mean that there is no cost.
